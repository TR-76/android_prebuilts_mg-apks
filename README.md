#AOSmium System Webview

This is a repositery hosting the make files and apk to successfully implement AOSmium System Webview in an ARM or ARM64 android device ROM. It adds the app to the system and removes AOSP's webview to do so. 

# Credits

* [AXP-OS](https://codeberg.org/AXP-OS/app_aosmium)


- Add the following directory structure to include AOSmium WebView:

  AOSmiumWebview/AOSmiumWebview_arm.apk
  AOSmiumWebview/AOSmiumWebview_arm64.apk
