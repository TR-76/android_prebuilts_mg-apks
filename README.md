#Cromite System Webview

This is a repositery hosting the make files and apk to successfully implement Cromite System Webview in an ARM64 android device ROM. It adds the app to the system and removes AOSP's webview to do so. 

# Credits

* [Cromite](https://github.com/uazo/cromite)


- Add the following directory structure to include Cromite WebView:

  cromitewebview/cromitewebview_arm64.apk
